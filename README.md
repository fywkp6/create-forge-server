## 开服前必须对齐的三件事

机械动力整合包开服失败，十次里有八次不是服务器的问题，是版本没对齐。

**第一，Minecraft 版本必须是 1.20.1。** 前面提到的“更多附属与优化”明确要求 1.20.1，齿轮盛宴、“来自蒸汽的信”也都是 1.20.1 世代。你从整合包页面下载的是什么版本，服务端就得是什么版本，跨版本不通用。

**第二，Forge 加载器版本要对上。** “更多附属与优化”基于 Forge 47.4.10 构建，服务端安装时选同一个构建号。Forge 版本差一个 build，模组就可能报缺失依赖或者直接拒绝启动。

**第三，客户端和服务端的模组列表必须完全一致。** 你本地装了多少个模组、什么版本，服务端就要有一份一模一样的。少一个客户端模组，玩家进来会卡在“连接中”；多一个服务端模组，客户端可能连注册表都对不上。

顺序上，先在面板里把服务端类型选成 Forge、版本填 1.20.1、构建号填 47.4.10，再把整合包服务端文件夹里的 mods、config 原样传上去。雨云的面板提供可视化文件管理，Forge 在支持的服务端类型列表里，传整合包不需要敲命令行。

还有两件常被忽略的：

**光影不用装在服务端。** 光影是客户端渲染层的东西，服务端装了没有任何效果，只会多占资源。像“永无止境”那类老包在说明里专门提醒“使用 Optifine 和光影需要自担风险”，讲的也是客户端兼容问题，跟服务端无关。

**端口要确认。** NAT 模式下默认不是直接给你 25565，需要在面板里手动做一次端口转发，再把“IP:端口”发给朋友。这一步漏了，服务端显示运行中，朋友就是连不上。

## 常见问题

**两个人能不能共用一台服务器？** 能，开两个服务端实例，各占一个端口，内存要对半分。但机械动力整合包单个实例就要 4GB 起，2核4G 的机器塞两个实例会互相拖累，不建议。

**要不要买独立 IP？** NAT 共享 IP 加端口转发就能用，把“IP:端口”发给朋友即可。独立 IP 的意义在于玩家不用记端口、部分服务端插件和远程访问更顺，人多了再考虑，不是开服必需项。

**整合包更新了，服务端要不要跟着换？** 要，而且是立刻换。整合包更新通常会动模组版本，客户端更新了服务端没更新，玩家会直接被踢。反过来服务端更新了客户端没更新，一样连不上。两边永远保持同一份模组列表。

**服务器卡，先查什么？** 先看服务端控制台的 TPS 和内存占用。TPS 掉到 15 以下但内存没满，是单核扛不住，换高主频机型；内存持续顶到上限、日志里出现 GC 或 OOM，是内存不够，加内存。两条都不是，再去查客户端光影和视距设置，那是玩家侧的事。

**面板服务器和 VPS 到底差在哪？** 面板是网页点选，选服务端类型、传文件、点启动，全程不碰命令行，适合第一次开服。VPS 给完整系统权限，要自己装 Java、写启动脚本、配防火墙，自由度大，适合要开多个服或者改 JVM 参数的人。
